Broker Connections & Portfolio Sync

Optional read-only integration with Zerodha Kite Connect v3 for real-time portfolio synchronization.

Fernet-Encrypted Secret Storage
Read-Only Research Architecture (Master Spec Section 22): All stored API secrets and access tokens are strictly encrypted using authenticated AES/Fernet cryptography. This module operates purely in read-only mode to synchronize existing portfolio holdings and quotes. No order placement, trading execution, or broker order modification capabilities exist on this platform.
